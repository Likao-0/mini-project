HTML

HTML stands for Hypertext Markup Language. It is the standard code used to structure and display content on the internet, acting as the fundamental "skeleton" or backbone of every website you visit.

Invented by Tim Berners-Lee in the early 1990s, HTML uses a system of tags to tell web browsers (like Chrome or Safari) how to display text, images, and links. It is a markup language, not a programming language, meaning it organizes text rather than executing complex math or logic.
