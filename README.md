# Mini Project

A simple multi-page website created as a collaborative Git and GitHub project.

## Project Description

This project demonstrates teamwork, Git workflow, collaboration, and merge conflict resolution.

The website includes three pages:

* **Home** — main page with general information.
* **About** — information about the team members.
* **Contact** — contact information and a contact form.

## Files

* `index.html` — Home page
* `about.html` — About page
* `contact.html` — Contact page
* `style.css` — Common styles for all pages

## Technologies

* HTML
* CSS
* Git
* GitHub

## Teamwork

The project was created by two students working together on the same `main` branch.

The team practiced:

* Creating and editing files
* Making commits
* Pushing and pulling changes
* Working with a shared repository
* Resolving a merge conflict
